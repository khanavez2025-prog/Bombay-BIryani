## 🍽️ How to Manage the Menu (Add / Remove Dishes)
Detailed instructions are available in [deployment_and_menu_guide.md](file:///C:/Users/dell/.gemini/antigravity/scratch/BOMBAY_BIRYANI_CATERING_WEBSITE/deployment_and_menu_guide.md).

### Quick Summary:
- Open `index.html` in any text editor (Notepad, VS Code).
- Scroll to the `<section id="menu">` area.
- **To Add**: Copy one of the dish `<div>` blocks and paste your new dish name & description.
- **To Remove**: Delete or comment out the dish `<div>` block.
- **To Change Category**: Set `class="col-md-6 col-lg-4 menu-item <category>"` where `<category>` is `biryani`, `mughlai`, `chinese`, `continental`, `juices`, or `icecreams`.
